## 초기 계산 도구 → 전자식 컴퓨터의 등장

### 컴퓨터 이전의 계산 보조 도구

- 네이피어봉
- 파스칼 계산기
- 라이프니츠 승제산기(곱셈/나눗셈)

### 바베지의 해석기계(1834)

- **차일스 바베지**가 “해석 기계”를 설계
- 오늘날 컴퓨터의 **5대 기능과 유사**하다고 평가되지만
- **실제 제작/구현은 되지 못함**

### ABC(1937)

- 최초의 전자식(진공관 사용) 계산기 성격의 컴퓨터
- 개발자 **Atanasoff**와 **Clifford Berry** 이름을 따서 **ABC**
- 단, **프로그램 내장/프로그래밍 가능 컴퓨터는 아님**

### ENIAC(1946)

- 최초의 **대형 전자식 디지털 컴퓨터**로 대표됨
- 진공관 약 **18,000개**, 무게 **30톤**, 한 방을 채우는 규모
- 용도: 포탄 궤도, 기상 예측, 난수 연구 등
- 프로그램 변경 시: 소스 작성이 아니라 **전선/스위치 재배치**

### 폰 노이만 방식(프로그램 내장 방식)

- **존 폰 노이만**: “메모리에 프로그램을 저장하고 그에 따라 실행”하는 방식 제안(1946)
- 폰 노이만 방식 컴퓨터가 1951년에 출시되었으나
- 실제 제작은 1949년 **모리스 윌키스**가 만든 **EDSAC**이 먼저
  - 따라서 “아이디어는 폰 노이만, 최초 구현은 EDSAC” 흐름으로 소개

## 컴퓨터 세대별 발전(핵심 정리)

> 세대 구분 기준: 주로 **논리 소자/집적 기술**의 변화

### 1세대: 진공관 시대

- 예: ENIAC, EDVAC, EDSAC, UNIVAC 등
- 특징/한계
  - 크고 무겁고 발열 심함
  - 수명 짧고 고장 잦음
- 이 시기 주요 회사 등장: IBM, 레밍턴 랜드 등

### 2세대: 트랜지스터 시대

- 진공관 한계를 **트랜지스터**가 해결 → 안정성/성능 향상
- 최초 트랜지스터 컴퓨터: **TRADIC**
- 기억장치/입출력도 발전(예: 자기 코어)
- 소프트웨어 측면 발전
  - 고급언어 등장: **ALGOL, FORTRAN, COBOL**
  - 운영체제 개념 확산 + **실시간 처리 기법** 등장
  - 입출력 대기 동안 CPU를 놀리지 않게 하는 기법(작업 전환 등)

### 3세대: 집적회로(IC) 시대

- 트랜지스터를 **집적(Integrate)** 해서 칩으로 구현
  - IC(Integrated Circuit), 마이크로칩
- 컴퓨터가 더 작아지고 싸지면서 저변 확대
- 예: **IBM 1130**(월 1000달러 이하 임대 사례 언급)
- 성능 향상 + 대량 생산 + 반도체 메모리 도입
- OS/처리기법 발전
  - 다중 프로그램, 병렬처리 개념 확대
- **마이크로프로세서**(CPU를 하나의 칩에) 등장 기반 마련

### 4세대: 초고밀도 집적회로(LSI/VLSI/ULSI) 시대

- LSI(고밀도) → VLSI(초고밀도) → ULSI(울트라)
- “작은 기판에 만 개~수백만 개 이상 집적” 같은 방향으로 설명
- 결과
  - 연산 속도↑, 저장 능력↑, 입출력 장치 발전
  - **개인용 컴퓨터 성능 급상승/가격 하락**
  - “지능형 터미널” 같은 개념(단순 입력 단말 → 일부 처리 가능 단말)
  - 데이터통신/분산처리/데이터베이스 보편화
- 예시로 언급된 메인프레임: **IBM 370**
  - 1980년대 한국에서도 많이 사용되었으나
  - 지금 PC 수준과 비교하면 매우 제한적이었다는 설명

## 마이크로프로세서와 PC의 대중화

### 인텔과 마이크로프로세서

- 1970년대 초 **인텔**이 마이크로프로세서 개발
- 집적기술 발전과 결합 → 성능 지속 향상

### PC 확산(1977 전후 사례 중심)

- **애플**, **매킨토시**, **IBM PC** 등장 → 개인용 컴퓨터 시대 확대
- 미국 외 지역에서는 **IBM PC 계열**이 더 널리 확산되었다는 흐름
- 결과: 가정에서도 데스크톱 컴퓨터를 갖는 시대

## 네트워크/인터넷 결합: 서비스 폭증의 기반

### 네트워크 발전

- 초기: 전화선 기반 연결
- 이후: **인터넷** 등장 → 급속 발전
- “무한한 가상공간에서 정보 획득”이 가능해짐

### 서버–클라이언트 구조의 확산

- 과거: 고가 메인프레임 중심
- 이후: 서비스별 서버 분화
  - 인터넷뱅킹 서버
  - 메일 서버
  - 쇼핑 서버 등
- 컴퓨터 성능 향상 + 비용 하락이 이런 서비스 확장을 가능하게 함
- 관련 개념: 분산 계산, 병렬 계산

### GUI의 등장(사용성 혁명)

- MS-DOS 시절: 텍스트 명령 중심 → 일반인 사용 난이도 높음
- 성능/용량 향상 후: **GUI**(그래픽 사용자 인터페이스) 확산
  - 마우스로 선택하는 방식(윈도우즈)
  - 스마트폰의 터치 조작도 GUI의 연장선

### 모바일로 확장

- 데스크탑 → 랩탑/노트북 → PDA → 스마트폰
- 웨어러블(시계/안경/이어폰 등)까지 확장
- 교재 후반(15강)에서 모바일 기기 추가 학습 예고

## 컴퓨터 + 통신 결합(데이터통신 → 인터넷 → 이동통신)

### 데이터통신의 의미

- 멀리 떨어진 컴퓨터/단말기 간에
  - 통신 회선을 통해 데이터를 주고받는 것

### “일괄처리 → 거래지향” 변화

- 과거(예: 1980~90년대): 시험 후 성적을 한꺼번에 메인프레임에서 **일괄처리**
  - 성적표를 우편으로 받아봄
- 통신 결합 후: 집에서도 학사시스템에 접속해
  - 성적 조회/출력, 수강신청, 각종 신청/응답 가능
- 이런 흐름이 “거래지향 방식” 설명의 요지

### 인터넷과 초고속망

- 광통신/위성통신 기반 초고속 정보통신망이 가정까지 확산
- 용어 예시: **ADSL, VDSL, FTTH**
- 결과: 시간·공간 장벽 약화, 글로벌 정보 공유

### 이동통신 세대(3G→4G→5G)

- 와이파이 + 이동통신 발전
- 5G가 제대로 구현되면(강의 표현)
  - 초고속(예: 최대 20Gbps 언급)
  - 초연결/초저지연 기반 멀티미디어 서비스 확대
- 속도 비유 그림(강의 소개)
  - 1G 자전거 → 2G 오토바이 → 3G 자동차 → 4G 비행기 → 5G 로켓 → 6G 우주선

## 미래 컴퓨터 산업(5세대 방향)

### 기술/하드웨어 전망

- 컴퓨터는 더 **저가·소형화**, 성능은 더 **향상**
- 병렬처리 기술 강화로 속도 향상
- 실리콘 외 **새 소자**(광소자, 조셉슨 소자, 갈륨비소 등)
- 대용량 메모리/보조기억장치(광디스크, 램 등)
- 클라우드 발전 → 이동형 보조기억장치 의존 감소 가능

### 서비스/응용 방향

- 멀티미디어(오디오·비디오·애니메이션) 서비스 확대
- 빅데이터 기반 정보 분석 확산
- 가상공간 기반 기술 발전
  - VR(가상현실)
  - AR(증강현실) 예: 건물을 비추면 정보 제공, 아파트 매물 정보 제공
  - 메타버스

### 지능형 컴퓨터와 유비쿼터스

- 인공지능형 컴퓨터, 머신러닝, 신경망 컴퓨터
- “사람처럼 듣고 보고 말하고 생각하는” 방향
- 초고속·초소형·초경량·초저가 컴퓨터가 생활 곳곳에 내장 → **유비쿼터스**
- 사물인터넷(IoT), 스마트시티
- 양자컴퓨터 연구

## 세대별 요약

### 하드웨어

- 1세대: 진공관
- 2세대: 트랜지스터
- 3세대: 집적회로(IC)
- 4세대: 초고밀도 집적회로(VLSI/ULSI)
- 5세대: 새로운 소자 + 지능형 컴퓨팅

### 소프트웨어/운영체제 흐름

- 1세대: 프로그램 내장 방식(폰 노이만), 기계어
- 2세대: 고급언어(포트란·코볼·알골 등), OS 확산
- 3세대: 다중프로그램/병렬처리 등 운영체제 발전
- 4세대: GUI 기반 OS(윈도우즈), 인터넷/WWW 확산
- 5세대: 자연어 기반 처리(알고리즘/코딩 없이 말로 지시 → 자동 처리) 지향
